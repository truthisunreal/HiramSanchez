§ 01 About

The work behind the work.

I work at the intersection of point-of-sale systems, SQL Server engineering, and the day-to-day technical glue that keeps an enterprise retail operation running. For the last eighteen years that's been at Duty Free Americas, where I'm the gatekeeper for POS change control and business-rule governance across 400+ registers and 200+ SQL servers running Oracle Xstore.

I'm probably most proud of POS Plus Platform — a suite of 30+ custom in-store applications I built and maintain, running 24/7 across all locations to extend Xstore functionality where the platform stops. Beyond that, my day looks like SQL schema work, ASP.NET application development, ERP integrations with Oracle Retek Resa and SIM, BI/SSRS reporting, and the occasional payment-hardware integration.

Lately I've leaned hard into AI-assisted development — Claude, GitHub Copilot, ChatGPT, Gemini, and Ollama for local models. The honest version of that story isn't "AI replaces engineers"; it's that I can now ship internal tools, automate documentation, and shorten time-to-resolution on complex incidents at a rate that wasn't possible two years ago.

I'm a calm problem-solver who likes owning things end-to-end — from debugging a register at the script level to architecting a new integration. Bilingual (English / Spanish). Based in Hialeah.

§ 04 Selected Work

How the work actually gets done.

→ 01 · Incident analysis

Production incident root-cause analysis

Investigated a reported data discrepancy between a store and the central Xcenter environment. Analysis of Xstore application and replication logs confirmed every record had replicated successfully after transient connection retries, isolating the issue to the central system and routing remediation to the right team.

→ 02 · Pricing research

Wholesale and KYC pricing in Xstore

Xstore has no native wholesale feature, so I delivered one by combining three existing engines: hierarchical item pricing, the deal engine with customer-group triggers, and manual discounts. I also delivered four KYC customer pricing tiers driven by MNT group assignments instead of cashier buttons.

→ 03 · Deal engine

Automatic loyalty deal

Built a transaction-wide 10% loyalty deal with customer-group triggers across five loyalty tiers, replacing a cashier-applied discount so qualifying customers get the price automatically.

→ 04 · Integration

Inventory movement automation

Built a scheduled integration that collects inventory movement files from every store every five minutes and stages them centrally for downstream processing, tagging each with store and timestamp and keeping daily audit logs with 30-day retention. Engineered in native Windows batch to meet a locked-down security policy.

→ 05 · Method

Research → lab → spec → build

Every project follows the same loop: read the Xstore manuals and the live schema, prove the approach in a lab database, write a PLAN.md / CLAUDE.md specification, then hand the build to Claude Code inside Visual Studio.

→ 06 · Enterprise rollouts

Payments, compliance, and new lanes

PCI compliance, EMV and contactless certifications, Dynamic Currency Conversion, loyalty integration, first-generation tablet POS, and customer self-checkout, plus Verifone pinpad and Zebra scanner integration across the fleet.

→ 07 · Multi-platform POS

More than one POS platform

Lead configurator for SAP POS 2.3 across multiple retail divisions: managing builds, testing every release, preparing gold images, and upgrading stores. Also trained and certified on GK Software POS, so I've run more than one platform end to end.

→ 08 · Digital signage & web

Store screens and the e-commerce back office

Run the in-store signage network with Samsung MagicInfo and BrightSign, scheduling content and pushing media to store displays. Separately built a custom Magento admin interface on the Magento API with VB.NET to manage the e-commerce site.
